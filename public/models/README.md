# Modelos 3D

Modelos GLTF (CC0) usados para os astronautas:
- `male_a.glb`, `male_b.glb`, `female_a.glb` — Kenney Mini Characters (CC0-1.0), obtidos via Papyszoo/CC0-Public-Domain-Models.
- `human.glb` — Cesium Man (CC BY 4.0), Khronos glTF Sample Assets.

Para substituir por modelos próprios, mantenha os nomes ou atualize `src/data/astronauts.json` (campo `model`).
Carregados via GLTFLoader em `src/core/astronaut.ts`.
